# 适用于方向 1–2 的研究提示词

[English](PROMPT.md) | 中文

聚焦动态环境中的鲁棒定位／SLAM，以及语义建图、视觉定位与导航。先复现所选作者流程并检查输出，不先选假设再将支持它的例子当作确认。

沿“位姿 → 对应关系 → 可见性／变化证据 → 对象／语义融合 → 地图更新 → 定位／导航查询”阅读 DUFOMap、BeautyMap、ConceptGraphs、HOV-SG、Khronos、DovSG 及可查证的近期时空地图。找出多项方法共享的假设，说明它为何使某类任务即便换网络或阈值也不可辨识／不可靠。

检查定位漂移能否像对象移动／消失、遮挡能否像不存在、相关观测能否被当成独立证据。这些是待查问题，不是假定失效。指出已有可见性、记忆和联合估计方法，用反例缩小瓶颈。

给出原章节、公式和代码位置，分清论文陈述、复现实测、结构推断与未测猜想。先对齐评价差异再声称失效；至少复现一个语义前端，再断言跨领域存在实测共性问题。

复现后形成候选假设。确认性实验前冻结留出场景／种子、仅验证集选阈值、覆盖率／延迟预算和否定条件。分开控制位姿幅度与相关性、锚点／运动比例、可见性和迟到修正；与简单阈值扫描比较，保留负面结果，同时报告风险、召回、覆盖率。

交付独立中英文仓库文档、固定版本和校验数据、原分数／日志、分阶段计划，以及实测 GIF／视频对照位置。从与评分相同的点身份渲染。合成机制是探索，不冒充完整 SLAM／导航，也不独立确认由这些结果选出的假设。
