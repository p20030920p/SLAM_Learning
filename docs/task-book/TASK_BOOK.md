## 1 · ⚠️ 漏洞检查：这套设计有 10 处不闭合

> 这是本文档最有价值的部分。每一条都给出**修正建议**。

### ⛔ H1 · 「提前 5–20 秒停车」在室内几何上不成立

**算术**：1.5 m/s（典型室内 AMR）× 20 s = **30 m**；5 m/s（室外）× 20 s = **100 m**。
而室内仓库/医院的通视距离常 **< 20 m**；2D 雷达有效距离通常 10–30 m；
双目深度在 >10 m 时方差急剧增大。

**结论**：靠**在线感知**不可能提前 20 秒看到障碍物——除非能看穿墙壁。

**修正**（重要，且对你有利）：把指标从"感知距离"改为
**「基于地图的风险区预告 + 在线确认」**：
- 上次会话已建图 → 地图中标记"曾经有水坑/反光区" → 进入该区域前提前减速
- 在线感知只负责**确认与更新**，不负责发现

> ✅ 这样一改，题目就从"感知问题"变成 **"跨会话地图记忆 + 退化感知 + 决策"**，
> 正好接上你之前选的"多会话地图修订"，也解释了为什么必须做地图层。

### ⛔ H2 · 2D 雷达与你列的障碍物清单物理上不匹配

| 你的目标 | 2D 雷达能看到吗 | 原因 |
|---|---|---|
| 水坑 | ❌ **看不到** | 在地面上；2D 雷达扫的是**一个水平切面**（通常 0.2–0.5 m 高） |
| 砖头 | ❌ 基本看不到 | 同上，且高度低于扫描面 |
| 细钢筋 | ⚠️ 极不稳定 | 截面小于角分辨率，单帧可能**一个点都没有** |
| 反光面 | ⚠️ 会看到，但是**噪声** | 镜面反射产生虚假回波——它是干扰源，不是可分类目标 |

**修正**：明确分工——
- **2D 雷达**：水平面障碍（墙、柱、人腿、货架）→ 定位与避障
- **双目/深度**：地面与近场（水坑、砖头、细杆）→ **必须下视视野**，不能平视

### ⛔ H3 · 「特殊障碍物」是四类不同的物理问题，不能当一个类做

| 类型 | 物理机制 | 哪个传感器失效 | 需要的检测思路 |
|---|---|---|---|
| **反光/镜面** | 镜面反射、多径 | 激光（虚假回波）· 双目（匹配失败） | 反射强度异常检测 + 多视角一致性 |
| **细杆/钢筋** | 亚分辨率、弱纹理 | 激光（点太少）· 双目（细结构难匹配） | 时序累积、近场高分辨、边缘先验 |
| **砖头/小凸起** | 几何可见 | 双目远距方差大；2D 雷达看不到 | 稠密深度 + 地面平面残差 |
| **水坑/负障碍** | 透明+镜面、**无深度** | 双目（无纹理可匹配）· 激光（无回波/穿透） | 纹理异常 + 偏振/多光谱 + 时序（水面会动） |

**修正**：做成**四个独立检测器 + 一个融合层**。
做成"一个特殊障碍物检测器"的结果是四类全都做不好。

### ⛔ H4 · 「通过行为观测精心定位」表述不清，必须先定义

三种可能读法，工作量差一个数量级：

### ⛔ H5 · 「语义分割实时更新标定」把两件事混在一起

标定 = **外参 / 内参 / 时间偏移**；语义 ≠ 标定。可能的两个真实含义：

|---|---|---|
| (a) **语义辅助标定**：用稳定语义类（地面、墙、杆）选特征做外参标定 | 合理且有用 | 有，但顶刊很少 |
| (b) 在线标定随时间持续更新（应对震动、温度漂移） | 工程刚需 | 有，多为 2018 前后 |

**修正**：拆成两条独立任务，不要合成一句。

### ⛔ H7 · 停车需求有控制与安全侧，你没有提

1. **制动距离 = 反应距离 + 制动距离**，而**水坑会延长制动距离**（湿滑）。
   也就是说水坑既是障碍物，又是"让刹车变差"的危险源——自相矛盾的需求。
2. **安全停车需要安全等级传感器**：ISO 3691-4（AMR 安全）、IEC 61496（光电防护）。
   消费级双目/深度相机**不是安全级器件**，不能单独用于安全停车。
   工程上通常需要安全激光雷达 + 安全 PLC。

**修正**：任务书里区分**「功能停车」**（性能层，可用消费级传感器）与
**「安全停车」**（认证层，需安全级器件）。不要混为一谈。

### ⛔ H8 · 退化场景清单混了不同的失效机理

| 场景 | 失效的子系统 | 对策 |
|---|---|---|
| **白墙** | 视觉前端（无特征）+ 激光退化（纯平面） | 结构/语义先验、多模态切换 |

## 4 · 需要补写的两节

### 4.1 地图更新策略（你的设定里缺这一节）

| 决策 | 依据 |
|---|---|
| 新增 | 多次观测一致 + 非动态 |
| 删除 | 持续未观测 **且** 该区域被充分观测过（可观测性！） |
| 修订语义 | 位置未变但标签变化 |
| **永久禁区** | 特殊障碍物 → 长期保留，即使本次没看到 |

> **关键**：删除判据必须包含**可观测性**——"没看到" ≠ "不在"。
> 这是整个系统最容易出错的地方，也是你之前那道题的核心。

### 4.2 评估指标（现成的不够用）

| 指标 | 为什么需要 |
|---|---|
| ATE / RPE（分场景） | 常规，但必须**按退化场景分层报告** |
| **标定误差 ECE** | 系统是否"知道自己不确定" |
| 特殊障碍物：检测率 / **误报率** | 误报会导致不必要停车，是产品级指标 |
| **提前量**（秒） | 从检出到停车的可用时间 |
| 地图修订：precision / recall | 写错地图比不写更糟 |

## 5 · 假设与证伪

**H1**：在退化场景中，**融合标定化置信度**的定位输出，比只用 ATE 优化的系统
在"失效检出率"上更高，且**误报率可控**。

**H2**：把特殊障碍物写入**跨会话地图**（而非每次在线检测），
可在**相同传感器**下把可用提前量从 < 3 s 提升到 > 5 s。

**H3**：**可观测性感知**的地图删除判据，比"未观测即删除"的朴素规则产生更少的地图错误。

**证伪条件**：若 H2 中地图先验带来的提前量提升 < 20%，H2 不成立。

| 项 | 内容 |

| 公开数据 | KITTI / MulRan / Newer College / Hilti（**均为 3D 雷达**，只能做算法验证，不能复现你的传感器配置） |

| 天 | 任务 | 硬性产出 |
|---|---|---|
| 1–2 | 传感器接入 + 标定 + 时间同步 | 标定残差 < 阈值 |
| 3–4 | VIO/LIO 跑通（FAST-LIO2 / VINS-Fusion） | 基线 ATE |
| 5 | 六个退化场景各采一段 | 六段数据 + 失败记录 |

### 并行实验（恢复自原 T1，建议保留）

在等待自采数据、或传感器接入受阻时，可以**立即开始**的一个独立小实验——
它不需要你的传感器，**纯 CPU、资产全公开**：

| 项 | 内容 |
|---|---|
| **问题** | 动态点删除方法按 F1 排序，与按"清理后地图的**定位可用性**"排序，是否一致？ |
| **假设** | H1′：两种排名不一致（Spearman ρ < 0.9）；且假阳性来自**可观测性低**的区域 |
| **工具** | `KISS-ICP` + `ERASOR` / `Removert` / `DUFOMap` / `BeautyMap` + `DynamicMap_Benchmark` |
| **数据** | KITTI odometry（需注册，免费） |
| **周期** | 5 天（环境 0.5 + 基线 1 + 清理 1.5 + 定位 1.5 + 分析 0.5） |
| **产出** | F1 排名 vs 配准失败率排名对比表 · 静态点删除率–定位失败率散点图 |

**为什么与主任务不冲突**：它研究的正是本任务书 §4.1「地图更新策略」的删除判据，
而且**直接给主任务提供"可观测性"这一核心概念的量化证据**。
若结果成立，它本身就是一份可独立汇报的成果。
