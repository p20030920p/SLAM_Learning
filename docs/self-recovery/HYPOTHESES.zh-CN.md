# 候选假设与最小实验

本文档只写**可证伪**的候选假设。每条包含：主张 / 文献缺口 / 最小实验（尽量只用现有平台）/ 需要补什么 / 证伪条件。

> **按论文/策略族分组的版本见 [HYPOTHESES-BY-PAPER.zh-CN.md](HYPOTHESES-BY-PAPER.zh-CN.md)**：那里把假设按 6 个策略族重排（抑制 / 检测 / 恢复动作 / 地图侧 / 确认 / 边界），每条绑定到现有仿真的具体一格，并给出本文档 H1—H6 到新编号的对照表。本文档保留指标定义、实验矩阵与两天计划。

> 状态：全部为**候选**，尚无实测。所有"能测 / 不能测"的判断基于对仓库现有脚本与回放产物的核对，以及 LILocBench 公开数据的实际页面核对。

## 0. 先把度量定下来（否则假设无法证伪）

一次"注入 → 检测 → 恢复 → 观察"回合为基本单位。符号：$t_{inj}$ 注入时刻；$e(t)$ 位置误差；$\tau_{good}$ 可信阈值；$\tau_{bad}$ 不可信阈值（与 $\tau_{good}$ 之间构成迟滞带）；$d(t)\in\{0,1\}$ 系统自报"我不可信"；$w$ 确认窗。

工作值（需在第一批回放上标定，不要预先当结论）：$\tau_{good}=0.3$ m，$\tau_{bad}=1.0$ m，$w=2$ s。

| 指标 | 定义 | 现在能否算 | 说明 |
| --- | --- | --- | --- |
| 失效率 FR | $P(e>\tau_{bad})$ 的回合占比 | ✅ 只需真值 | 场景难度基线 |
| 检测混淆矩阵 | TPR / FPR / FNR + **误报代价**（$\tau_{good}$ 内被误判导致不可用的时间占比，或触发的重定位次数） | ⚠️ 需补记录 $d(t)$ 的内部量 | **唯一能分离"检测失败"与"恢复失败"的手段**；误报代价必须与 FNR 并列报告，否则系统会被优化成"一直喊不可信" |
| 自恢复成功率 SRR | 存在 $t_r$ 使 $e\le\tau_{good}$ 在 $[t_r, t_r+w]$ 内持续成立（期间不得再越过 $\tau_{bad}$）的回合占比 | ✅ 只需真值 | 需迟滞定义，防止"抖一下算恢复" |
| 恢复时延 TTR | $t_r-t_{inj}$，报 **中位数 + p90 + 最大值** | ✅ 只需真值 | 只报中位数会掩盖长尾（现有唯一报 TTR 的工作只报了中位数） |
| 复发率 RDR | 恢复后观察窗内再次越过 $\tau_{bad}$ 的回合占比 | ✅ 只需真值 | 回答"恢复后是不是又坏了" |
| 可信度校准 | ECE，或 $\mathrm{Spearman}(e,\hat\sigma)$ | ⚠️ AMCL 无解析协方差，用粒子云散布度 / 最优粒子权重 / 激光似然均值作可信度代理 | NEES 不可用（需要一致的协方差估计） |
| 阈值 $k^*$ | 连续加码扰动，FR 跨 50% 时的临界强度 | ✅ | 例如"改动比例"或"移动箱子数量"的临界值 |
| 退化条件-后果矩阵 | {场景条件} × {RMSE, FR, SRR, TTR_p50, TTR_p90, RDR} | ✅ | 最终对外的主表 |

**不建议做 MTBF**：需要大量 i.i.d. 回合，现有 42 次远不够，且容易被误读为系统级可靠性指标。用 RDR 替代。

## H1｜失效二相性：退化型与大变动型在系统内部量上可分

**主张**：同一套 2D 激光定位系统里，两类失效在内部统计量上可分——
- **退化型**（信息不足）：似然面平坦/多峰，粒子云发散或权重塌缩，最优粒子权重低；
- **大变动型**（地图失配）：似然面**尖锐**但系统性偏向错误位置，且"地图未解释的观测占比"高。

**文献缺口**：现有判据（信息矩阵谱、Fisher 加权、似然统计）都在优化器自己的坐标系里报告，且假设退化是"当前帧 vs 地图"的局域几何属性；没有人把"失败原因"当作需要分出的类别，而恢复动作恰恰依赖归因。

**最小实验**：把现有三组回放（纯静态 / 动态箱子 / 干净地图+动态）与新造的"地图改动 k 档"组并置，对每个时刻提取候选特征：$w_{fast}, w_{slow}$、粒子云协方差与多峰性（聚类数/最大簇权重）、最优粒子似然、扫描残差统计（未解释观测占比）。做二分类，报告 AUC 与混淆矩阵，而不是只看分类准确率。

**需要补什么**：在回放脚本里记录上述内部量（当前未记录）。**不改场景**，属于纯日志改造。

**证伪条件**：两类场景在这些统计量上不可分（AUC ≈ 0.5）；或分类边界随场景/地图漂移，无法跨场景迁移。

## H2｜恢复动作的条件有效性：归因决定动作

**主张**：恢复动作的收益依赖失效类型——
- 对**大变动型**，盲目全局重定位/随机注入无效甚至有害（会收敛到改动区域外的错误对称位置），必须允许地图侧动作（局部重定位 + 多地图假设 / 局部地图修正）；
- 对**退化型**，运动激励（主动移动到有静态锚点的区域）比随机注入更有效；
- 存在按归因选择动作的策略，其 SRR 与 TTR 优于任何单一固定策略。

**文献缺口**：恢复动作几乎全是"盲"的：AMCL 用单标量似然比触发盲目随机注入；多地图范式（跟踪丢失→新建地图→再合并）把"恢复"变成"重新开始"；鲁棒后端只保证对离群点不敏感，不保证从已污染的初值回到真解。

**最小实验**：在场景矩阵上比较五种恢复策略：{不做, AMCL 内置随机注入, 全局重定位, 运动激励, 归因选择}，报告 SRR / TTR / RDR / 误报代价。

**需要补什么**：需要一个"能主动运动"的测试轨迹生成方式（Gazebo 里给定目标点即可），以及把"归因"接进恢复触发逻辑的最小脚本。

**证伪条件**：单一固定策略在全部场景上不劣于归因策略（SRR 与 TTR 无显著差异）。

## H3｜恢复能力的信息下界（否定性结论）

**主张**：当机器人处于"与地图完全不一致"的区域，且该区域内不存在与地图一致的静态锚点时，任何**不改地图、不引入外部信息**的定位器都无法恢复到可信位姿（SRR ≈ 0）。恢复能力存在一个由"未变静态锚点占比 $\rho$"决定的下界与临界 $\rho^*$。

**文献缺口**：已知"直匀隧道对纯 LiDAR 配准在轴向永远不可观测"这类单点否定结论（[arXiv:2608.19522](https://arxiv.org/abs/2608.19522)），但没有人把"恢复能力"作为一个随场景变化量扫出边界；也没有人给出"允许地图侧动作后可恢复"的对照曲线。

**最小实验**：地图扰动比例 sweep（走廊段改动 0 / 25 / 50 / 75 / 100%），记录 SRR($\rho$) 曲线；再用"允许局部地图修正"的策略跑同一条曲线。两条曲线之间的差就是"地图侧动作"的可测价值。

**证伪条件**：不改地图的定位器在 $\rho\to1$ 时仍能可靠恢复。这本身也是重要发现（说明似然场对结构性改变不敏感，或残存结构足以约束位姿），必须如实报告。

**注意**：这条是主线的"骨架结论"——即使 H1/H2 都成立，没有 H3 的边界，工作会显得只是在工程上调参。

## H4｜内置恢复机制不报告成功（恢复确认缺失）

**主张**：AMCL（augmented MCL：$w_{fast}/w_{slow}$ + 随机注入）具备事实上的恢复动作，但没有任何"恢复成功"的判据。因此存在一个可观测的失败模式——**"自认为恢复（粒子收敛、权重回升）但真值误差仍大"**（unreliable-but-stable），且该时段占比在"动态 + 改动"场景下显著高于静态场景。

**文献缺口**：经核验，现有工作**没有定义恢复成功**；随机注入恢复后不会告知是否成功。"知道错了"与"回到对的位置"之间是断的。

**最小实验**：从已有 42 次回放出发（补齐 $w_{fast}, w_{slow}$ 与注入事件记录），统计"权重回升时刻"与"真值收敛时刻"的错配率与错配时长。

**证伪条件**：权重回升与真值收敛高度一致（例如 $\tau$ 秒内一致率 > 95%），即 AMCL 的置信度足以作为成功判据。

## H5｜检测器本身的等变性缺陷（零成本，建议第一批做）

**主张**：现有基于信息矩阵/似然统计的退化判据不具备刚体等变性：同一观测、同一世界坐标系，仅把**机体原点**平移或旋转，判据输出的"退化方向/失效标签"会发生翻转。因此"用逐轴退化标签触发恢复"在 2D 定位里会带来可测量的虚警代价。

**文献缺口**：该现象已在 3D LiDAR 配准上被证明（[arXiv:2608.15532](https://arxiv.org/abs/2608.15532)：无噪声圆隧道中把原点平移 1 m，被标为退化的自由度就变了），但**没有人把它的后果接到恢复闭环上**（即：这种不稳定判据会带来多少虚警、多少无效恢复）。

**最小实验**：用已录的静态回放数据，在机体原点平移/旋转的多个取值下计算 2D 退化判据（扫描匹配 Hessian 的谱、或 $2\times2$ 信息矩阵的广义特征值），统计标签翻转率，并把它换算成"触发的恢复次数/虚警时间"。

**需要补什么**：只需离线计算脚本，**不需要新仿真、不需要新硬件**。

**证伪条件**：翻转率随机体原点变化可忽略（< 5%），或翻转不影响恢复决策。

## H6｜桥接假设：动态遮挡与结构改动可用"持久性"分开

**主张**：动态遮挡与结构改动在单帧观测上是同一件事（地图未解释的观测），差别在时间统计——动态是短暂的、在不同位置重复；改动是持久的、在同一位置重复。用"未解释观测的持久性"作判据，可以把 DUFOMap / BeautyMap 那类**动态点过滤**升级为**地图过期检测**，且这个判据比逐帧退化标签更稳定（H5 的问题不直接适用）。

**为什么值得提**：这是新主线与保留的两篇论文（DUFOMap / BeautyMap）之间唯一的接口；如果成立，"地图清理 → 地图过期"就是一条自然的技术演进线，而不是两个不相干的题目。

**最小实验**：在 Gazebo 里同时放"长期静止的箱子"（伪结构改动）与"来回移动的箱子"（动态），记录每个未解释观测簇的位置持久性分布，看两类是否可分。

**证伪条件**：移动箱子长时间停在原地时与结构改动不可分（预期会出现，需给出"停留多久会混叠"的临界时长）。

## 场景矩阵（两天内优先跑核心格）

| 轴 | 取值 | 实现方式 | 是否已有 |
| --- | --- | --- | --- |
| 动态 | 无 / 三个移动箱子 | Gazebo 世界 | ✅ 已有 |
| 地图一致性 | 一致 / 改动 25% / 50% / 75% / 100%（走廊段） | 优先用直接编辑 `map` 的 pgm+yaml（零仿真成本）；再用"建图后改世界"复现 | ❌ 新增 |
| 几何退化 | 结构化房间 / 长走廊 / 空旷区 | Gazebo 世界 | ❌ 新增 |
| 注入 | 无（自然失效）/ 瞬移（kidnapping）/ 初始位姿偏移 | Gazebo set_pose 或 AMCL 初值 | ⚠️ 部分 |
| 恢复策略 | 不做 / 随机注入 / 全局重定位 / 运动激励 / 归因选择 | 定位侧脚本 | ⚠️ 仅前两项现成 |

核心格：{动态 2 档} × {地图一致性 5 档} × {恢复策略 5 档}，每组 ≥3 次重复（沿用固定随机种子）。约 150 次回放——单次成本与现有 42 次同级，两天内可完成主体，不足部分如实标注为"未跑"。

## 两天推进计划

**第 1 天**
1. 补日志：$w_{fast}, w_{slow}$、粒子云统计、注入/重采样事件、未解释观测占比；与真值同时间轴对齐 → 每次回放一份 `recovery_trace.csv`。
2. 跑 H5（纯离线，几小时，零场景成本）。
3. 造"地图改动 k 档"（先做 map 编辑版）+ 长走廊档，跑 AMCL 默认恢复基线。

**第 2 天**
4. 实现最小检测器（H1 的二相分类）与持久性判据（H6）。
5. 接上五种恢复策略，跑核心矩阵，出 SRR / TTR / RDR / 误报代价与 $\rho$-SRR 曲线（H3）。
6. 有余力则把同一协议搬到 LILocBench 的 4 个公开真值序列（`mapping, static_0, dynamics_0, lt_changes_0, lt_changes_dynamics_0`，no-camera bag + 官方 occupancy map），检查结论是否只在仿真成立。
7. 产出：双语图表 + 一页结论 + 反例与未跑项清单。

## 可能被否掉的地方（提前写清楚）

- 如果 H1 不成立（两类失效不可分），主线要退回到"统一判据 + 更强恢复动作"，H2 的归因部分作废。
- 如果 H4 成立而 H2 不成立，说明瓶颈在"确认"而非"动作选择"，工作重心应转向恢复确认机制。
- 如果 H3 的 $\rho^*$ 很大（改动 25% 就完全无法恢复），说明"不改地图"的定位器在本平台上非常脆弱，那时主线应整体转向地图侧（这正好接上保留的 DUFOMap/BeautyMap 与地图维护文献）。
