# 定位自恢复主线

**方向：Robust localization and SLAM in dynamic environments。开放问题：在退化与大变动环境中，什么样的策略能够有效地让定位系统自恢复？**

首轮研究二维 MCL 的恢复触发、候选位姿和持续确认。先建立简单恢复基线，测误重置、错误确认及可信可用时间；是否加入学习模型、失效归因和地图更新，由结果决定。

## 已有工作的范围

DUFOMap／BeautyMap 提供地图清理对照。IR-MCL 提供神经占据场观测模型的定位复现。AdaM-MCL 提供可采样观测模型与绑架恢复思路。LILocBench 提供长期变化下的真实定位评测条件。按各自原协议复现，再决定共同平台中哪些机制值得比较。

历史地图过滤实验主要观察厘米级位置误差；尚未构成失效注入与恢复实验。S1—S4 场景准备与实时录制也需分别通过传感器、坐标系和视觉验收，不能把有文件或有帧率视为成片。
