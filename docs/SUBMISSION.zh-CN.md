# 准备一个经得起面试检查的仓库

[English](SUBMISSION.md) | 中文

仓库应让评审沿着 **研究主张 → 图／视频 → 指标 → 运行记录 → 固定版本命令** 核查。主页美观的前提是这条链成立。四篇相关论文形成一个明确范围；增加无关方法不会让论证更强。

## 两分钟内主页需要回答什么

| 问题 | 交付 |
| --- | --- |
| 研究问题是什么？ | 空间对应与地图决策的收窄问题，并给已有反例 |
| 实际复现了哪些？ | 四张论文卡，区分完整 teaser 和语义核心子集 |
| 测量了什么？ | 原日志、可移植记录、评价定义、论文表格差值 |
| 有什么能看／能读？ | 每个完成的核心运行有 MP4／GIF 和独立中英文 PDF |
| 假设是什么？ | 候选机制、最小实现、竞争基线、否定标准 |
| 还欠什么？ | 明列标注独立审核、完整语义准确率／图／导航、实物采集 |

主页保留一张主要实测图，再给四篇的简洁表格；安装细节放复现页。视频标明输入、方法、位姿来源、坐标和运行编号；渲染回放不能暗示实时速度或屏幕录制。PDF 的范围与数值应和论文卡一致。

## 发邮件前的验收

1. 退出登录后打开公开 **main**，逐个检查论文／媒体／PDF 链接，不依赖私有缓存路径。
2. 干净环境执行快速冒烟命令，校验提交的证据；重型复现有独立命令与依赖。
3. 保留失败、论文差值和完整资源／兼容适配，不把组件执行改名为整篇验证。
4. 每次事实修正同步双语，核查建图入口的实际位姿输入，不能只从加载器默认值推断坐标。
5. MP4 解码帧数对应元数据；PDF 逐页渲染无裁切，视频检查首／中／尾帧。
6. 看留出数据之前冻结确认协议，已看过的 room0／合成结果只作探索。
7. 包含 AI 使用说明、数据／权重来源、许可说明、限制和简明面试路线。

## 十分钟讲解

前两分钟讲问题与四篇相关性；三分钟讲运行和实际回放，解释 5.347532 个百分点评分差异及坐标核查；三分钟讲假设、阈值／可见性竞争基线和能否定它的结果；最后两分钟讲固定／手持实物方案及没有机器人的范围。

应能推导共享偏差方差、解释失败并亲自重跑命令。评审可能问：为什么重复观测相关，隐藏为什么不等于移除，cosine 为什么不是概率，对象数为什么不是语义准确率。答案应依赖提交的证据，而非背诵普遍改进的结论。

“本库在完整公开 teaser 上复现 DUFOMap／BeautyMap 作者动态地图流程，在明确限定的 Replica 子集上复现 ConceptGraphs／HOV-SG 建图核心。研究空间对应如何影响地图决策，报告评分及坐标约定差异，提出可否定的共享位姿假设。提供视频、双语报告及 D435i／L2 实物协议；不宣称完整语义 benchmark、导航或实物验证已完成。”
