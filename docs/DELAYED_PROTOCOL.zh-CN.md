# 迟到位姿修正是否需要重新关联

[English](DELAYED_PROTOCOL.md)

本实验检验候选 H1 的前提：只修正几何、保留历史关联决策后，是否仍有全量重新关联能够恢复的目标损失。它不验证有界缓存方法、估计不确定性、真实物体运动、导航或四篇论文的共同瓶颈。

## 冻结与独立参考

[机器可读设计](../configs/delayed_pose.json) 已在下载本次新 Replica `room1` 子集前提交。建图使用源帧 0,25,...375，参考视角 12,137,262,387 不进入建图或前端提取。实例多边形与部分可见表面来自原始 RGB-D，预测掩码不定义真值。标注身份、排除项、查询及哈希必须在查看 SAM／CLIP 或地图结果之前封存。AI 辅助多边形仍需独立人工复核；复核之前，目标结论保持暂定。

数据采用 NICE-SLAM 发布的渲染 Replica，标定及 camera-to-world 位姿遵循固定版本的 ConceptGraphs loader。RGB-D 文件校验 ZIP CRC，并记录 SHA-256。源清单和独立标注冻结记录绑定输入。新场景提供证据分离，不等于多个独立场景的确认；已有 `room0` 结果参与了全部设计选择。

## 干预与对照

前八个观测注入世界 x 随机游走平移，归一化为 10 或 30 cm 的前缀 RMS，首位姿固定，种子 417／518／619。第八个观测结束后，所有历史位姿的精确修正同时可用，后续观测使用精确给定位姿。这是受控 oracle 干预，不是真实 SLAM 误差测量，也不注入旋转。

| 对照 | 修正之前 | 修正时 |
| --- | --- | --- |
| 原核心 | 作者关联，阈值 1.2 | 保留已融合历史，后续观测用正确位姿 |
| 阈值 | 阈值 1.0，来自之前 room0 探索 | 同原核心 |
| 可见性 | 阈值 1.0，增加可见投影支持检查 | 同原核心 |
| 固定关联 | 阈值 1.2，记录诊断用决策轨迹 | 用正确位姿重建全部前缀几何，强制保留原关联序列与语义成员 |
| oracle 全量回放 | 阈值 1.2 | 丢弃前缀状态，用正确位姿从头运行整个前缀，重新关联 |

可见性保护要求候选对象投影至少有 16 个深度一致的唯一像素，其中至少 20% 落在检测掩码内，深度容差 10 cm。不允许融合时建立新对象，不删除检测。这个便宜基线可能增加身份碎片，需要一并报告。

固定关联对照刻意给予完整观测与 oracle 位姿：按原 add／merge 顺序重建几何，而不是平移一个融合后的质心。八帧修正之前没有计划中的原生去噪／过滤／对象合并事件，因为相应周期长于前缀。如果位姿影响了三维检测的接受集合，须记录，并停止把该差异称为纯关联效应。固定关联与回放都是全历史诊断 oracle，不是计划中的 16 观测／512 MiB 原型。

使用固定作者前端和建图算子。掩码与 CLIP 特征只提取一次，建图不重新运行前端。包括原生校验在内，各对照按源观测重置点构造 RNG，防止关联分支改变未来抖动样本；披露这项执行适配。零误差下检查提取的循环与固定 batch mapper 一致，并检查原核心、固定关联、全量回放一致。校验失败时，先修复并保留记录，不能继续作因果解释。

## 读数与判断

在修正刚发生、后续四个和八个观测后评价。部分表面覆盖、可见精度、实例恢复、已标实例混合、碎片、受限类别 top-1 和目标表面坐标距离分别报告。参考视角不进入建图，但标注只覆盖部分可见实例；返回有效未标实例不能自动称开放世界假阳性。观测数不是墙钟更新延迟。

主要比较是 oracle 回放与固定关联几何。在某个 RMS 下，至少三个种子中的两个出现恢复／身份或受限查询改善，且零误差校验通过，才支持继续做有界回放原型。单纯坐标距离变好不够。简单保护已达到同样恢复时，应收窄动机；全量重新关联没有额外恢复时，不据此实现 H1。报告全部种子、两个 RMS，包括相同和负面结果；种子范围不是置信区间。

场景静态，不能检验真实变化召回、动态目标过期时长或匹配风险—召回—延迟的前沿。正面结果仅支持下一步测试真实变化和迟到的估计位姿修正。负面结果应导致停止或修改 H1，不能悄悄换一个有利场景。
