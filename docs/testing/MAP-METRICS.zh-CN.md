# 按实验任务选择指标

[首页指标](../HOME.zh-CN.md#指标) · [方法实践](../HOME.zh-CN.md#practice-index) · [自写假设](MAPPING-FOCUS.zh-CN.md)

A 先建图，冻结地图后再用独立采集 B 评价定位；两阶段分表。DA/SA 是删除与保留比例，不是地图几何精度或定位误差。

| 实验 | A：建图／清图 | B：在冻结地图中定位 |
| --- | --- | --- |
| DUFOMap／BeautyMap 清图复现 | DA、SA | 此项未测 |
| SRRG 静态／长廊对照 | SA | XY 与偏航 RMSE |
| SRRG 动态场景 | DA、SA | XY 与偏航 RMSE |
| FAST-LIO 去畸变 | 地图几何 RMSE；运动阶段另标里程计误差 | XYZ 与旋转 RMSE |
| IR-MCL／AdaM-MCL 定位复现 | 不评地图删除与保留 | 位置误差；IR-MCL另列偏航误差 |
| 自写 H1 | 动态 DA、SA；静态只列 SA | XY RMSE |
| 自写 H2 | 地图几何 RMSE | XY RMSE |

DA＝删除的动态参考单位数／动态参考单位总数；SA＝保留的静态参考单位数／静态参考单位总数。二维的单位是已观测空间支持，三维是参考点；不同单位、数据集和阈值之间不直接排名。没有动态目标时省略 DA。

自写H2的地图RMSE是地图到已观测静态支持的单向距离RMSE，不能单独衡量完整性。B 的位置 RMSE 由估计位置与真值计算，二维用 XY、三维用 XYZ。

展示页省略 AA/HA、P95、样本数、更新覆盖率及重复阈值统计。完整数值、有效输出范围和失败信息仍在原始评分记录中；缺失输出不能当成零误差。

当前 B 测的是机器人运动过程中的定位，尚未测完整导航任务的到达效果。清图比例改善，只支持清图结论；B 误差下降后才能支持下游定位改善。

[本轮数学定义与符号](MAPPING-FOCUS.zh-CN.md#数学表达)：以相同观测支持比较两图，DA提高且SA损失≤1个百分点，称动态残影清理改善；这不等于几何或定位改善。
