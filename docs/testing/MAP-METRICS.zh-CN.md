# 地图指标与退化时间点

[实践](../HOME.zh-CN.md#practice-index) · [极简表](../MINIMAL.zh-CN.md) · [原始分析](MAP-2D-3D.zh-CN.md)

原先把定位 RMSE 当作清理算法的主要效果，容易把“定位未改善”误写成“算法无效”。清理主要看动态障碍物删除和静态障碍物保留；定位误差是独立的下游指标。两者应同时保留。

| 方法 | 动态删除 | 静态保留 |
| --- | --- | --- |
| Raw，三维动态图 | 0% | 100% |
| DUFOMap，三维动态图 | 46.59% | 99.998% |
| BeautyMap，三维动态图 | 74.36% | 81.15% |
| Raw，二维动态投影 | 0% | 100% |
| DUFOMap，二维动态投影 | 8.33% | 100% |
| BeautyMap，二维动态投影 | 33.33% | 96.64% |

三维计数来自同步动态箱体表面标签和精确点保留掩码；二维重新评分实际 5 cm 投影图：1162 个静态专属格、168 个动态专属格，排除 2 个动静重叠格，保留原投影的一格膨胀。静态场景依据场景中没有运动物体，将排除车体近距离回波后的观测作为静态支持。三维点和二维格的分母不同，不能混用百分数。源点、标签和投影均保留在记录中。[可重算脚本](../../src/scripts/presentation/map_quality_report.py) · [二维记录](../../results/analysis/map-quality/projected-dynamic.json)。

定位变化小的候选解释包括：本次原始三维点仅约1%属于动态目标，静态墙面可能仍提供主要匹配支持；BeautyMap删除更多动态点，也损失更多静态支持。这些观察尚未通过受控实验建立因果关系，现有单次定位差别也不足以作稳定排名。投影可能将不同高度、不同时间的点映射到同一格，删除部分三维点后格中仍可能有支持；高度带、自由空间处理和膨胀也需要逐项诊断。点级与格级百分数不同，本身不能证明“投影丢失清理收益”，相关数字保留为[表示／评分诊断](MAPPING-FOCUS.zh-CN.md#原m3改为表示与评分诊断)。

| 退化记录 | 可核查时间（仿真秒） | 含义 |
| --- | --- | --- |
| 旧二维 `robot-corridor-v2` | 66.2 s 恢复观测；约 79.5 s 持续收敛 | 纠正初始定位偏移，不是在线建图故障／清理生效时刻 |
| 旧三维 `robot-3d-corridor` | 62.1 s 恢复；Raw／DUFOMap／BeautyMap 最后有效输出约 63.5／76.4／119.3 s | 有效定位输出覆盖不同；不是地图损坏时刻 |
| 旧二维／三维固定地图实验 | 建图故障起点未记录 | 未在线更新，不能从定位误差推断某秒地图开始出错 |
| 新 SRRG 走廊建图 | 11.1s首次跟踪重置（录制仿真偏移3.6s，MP4约4.6s） | 作者建图跟踪器告警，可作为手工检查起点；不是独立测得的几何坍塌时刻 |
| 新 SRRG 走廊建图 | 11.5s持续位置偏差超过20cm；57.6s恢复观测 | 定位预警和输入恢复分别记录；最终静态覆盖Raw83.43%、SRRG82.24%，本次未改善 |
| SRRG 动态图合并开启诊断 | 最后成功66.0s（录制仿真偏移55.4s），随后更新崩溃 | g2o数值分解失败；与二维点删除率无关，不能把崩溃后冻结画面当作有效输出 |

新视频同时给出仿真时间、从录制开始计算的仿真偏移。视频自身按墙钟计时，仿真可能慢于实时，不能直接把仿真偏移当作 MP4 秒数。需要逐帧定位时以录制时钟／终端显示为准。

动态分母为空时记 **N/A**，不能写 0% 或“没有改善”。持久结构变化若只用了旧图、未执行地图更新，则只报告 A 地图原有指标，并标记 B 未测。IR-MCL／AdaM-MCL 以及 H1–H3 定位原型的地图清理指标不适用，继续报告各自定位／恢复指标。
