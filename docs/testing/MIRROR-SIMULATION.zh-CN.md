# Gazebo 镜面仿真：实现方案与实验设计

更新：2026-10-15。

**状态：已核对现有仓库配置与 Gazebo Rendering 8 源码；尚未实现插件、运行镜面实验或完成实物标定。** 本文中的场景、接口和指标是后续实施方案，不是已有实验结果。

## 1. 当前配置能做什么

现有[静态场景](../../config/presentation/worlds/S1_static.world)使用 Ogre2；[机器人 URDF](../../config/robot_profiles/omni-3d-v1/omni_car_lidar3d.urdf)中的二维、三维雷达均为 `gpu_lidar`。历史深度假设组由[传感器配置脚本](../../src/scripts/presentation/probe_sensors.py)加入通用 `depth_camera`。

Gazebo Rendering 8 的 `gpu_lidar` 从深度缓冲恢复三维位置，再计算距离，回波强度另行处理；该测距路径没有追踪镜面反射后的光路。因此，修改金属度、粗糙度或 `laser_retro`，不能直接实现镜面造成的镜后虚假点。[官方测距源码](https://github.com/gazebosim/gz-rendering/blob/gz-rendering8/ogre2/src/media/materials/programs/GLSL/gpu_rays_1st_pass_fs.glsl) · [材质切换与 laser_retro 源码](https://github.com/gazebosim/gz-rendering/blob/gz-rendering8/ogre2/src/Ogre2GpuRays.cc)。

| 实现层次 | 可以模拟的内容 | 用途 |
| --- | --- | --- |
| 镜面外观 | 高金属度、低粗糙度、环境反射贴图 | 展示反光外观 |
| 镜面区域测量异常 | 在命中镜面的扫描方向上加入缺测、偏差等 | 明确声明的受控故障注入 |
| 几何反射光路 | 查询镜面交点、反射方向、二次命中和路径长度 | 有几何光学依据的传感器模型 |

Gazebo 官方环境贴图示例使用预先生成的立方体贴图，不应将其当作传感器已经模拟了真实镜面多径的证据。[Environment Map](https://gazebosim.org/api/rendering/8/envmap.html)。

## 2. 建议实现：平面镜的几何反射模型

从静态房间派生镜面场景，为同一块薄板保留完整碰撞几何，并向传感器模拟模块提供镜面位置、有限边界、朝向和材料参数。

建议流程：

```text
场景真实几何 + 镜面参数
           ↓
逐束射线查询与反射模型
           ↓
模拟 /scan 或 /points
           ↓
建图方法 → 冻结地图 → 独立定位
```

镜面参数和真实几何用于生成传感器数据；被测建图、定位算法只读取声明的传感器输入。镜面真值标签单独交给评分器。

### 2.1 射线与有限镜面求交

设雷达原点为 $\mathbf o$，发射方向为单位向量 $\mathbf d$，镜面经过 $\mathbf p_0$、单位法向为 $\mathbf n$。镜面交点满足：

$$
t_m=\frac{\mathbf n^\top(\mathbf p_0-\mathbf o)}{\mathbf n^\top\mathbf d},\qquad
\mathbf x_m=\mathbf o+t_m\mathbf d.
$$

仅在分母不接近零、$t_m>0$、交点位于有限镜面内且镜面没有被其他物体遮挡时，进入反射计算。普通表面仍采用普通测距。

### 2.2 计算反射方向与虚假返回

理想平面镜的反射方向为：

$$
\mathbf d_r=\mathbf d-2(\mathbf d^\top\mathbf n)\mathbf n.
$$

从 $\mathbf x_m+\varepsilon\mathbf d_r$ 出发沿 $\mathbf d_r$ 再次查询场景，避免射线立刻命中镜面自身。设二次命中点为 $\mathbf q$。

在理想的往返路径可逆、目标能够提供可检测回波的假设下，测距对应的单程路径为：

$$
r_{\mathrm{meas}}=\|\mathbf x_m-\mathbf o\|+\|\mathbf q-\mathbf x_m\|.
$$

传感器仍按原发射方向解释距离，因此表观点为：

$$
\mathbf p_{\mathrm{apparent}}=\mathbf o+r_{\mathrm{meas}}\mathbf d.
$$

这可能产生镜面后方的虚假结构。该公式描述理想几何路径，不保证每次反射都能被接收；实际材料、入射角、波长和设备检测机制还会影响返回。相关实测研究区分了反射面、反射物体以及玻璃后的物体等返回。[反射检测与 Plane SLAM 研究](https://arxiv.org/abs/2406.10494)。

### 2.3 回波状态与参数

镜面区域至少区分三种返回状态：镜面表面返回、反射路径返回、无有效回波。状态概率可写为：

$$
(p_s,p_g,p_d)=f(\theta,r,\text{material}),\qquad p_s+p_g+p_d=1.
$$

这里 $\theta$ 是入射角，$r$ 是距离；$s,g,d$ 分别表示表面、虚假返回和缺测。没有实物数据时，这些概率只能作为公开声明的实验变量，不能声称已复现 Unitree L2 的真实响应。需要考虑量程、检测阈值及跨帧相关性；不可仅把全图独立随机删点称为镜面物理仿真。

### 2.4 伪代码

```text
for 每个传感器时刻:
    获取该时刻的传感器位姿和场景状态

    for 每束激光:
        hit = 查询真实场景的第一个交点

        if 没有命中:
            输出无有效回波
        else if hit 不是镜面:
            输出普通测距
        else:
            xm, n = 镜面交点和法向
            dr = d - 2 * dot(d, n) * n
            q = 从 xm + epsilon * dr 沿 dr 查询场景
            mode = 根据入射角、距离和材料模型确定回波状态

            if mode 为表面返回:
                输出镜面距离及对应噪声
            else if mode 为反射返回 且 q 存在 且满足检测条件:
                输出 distance(o, xm) + distance(xm, q) 及对应噪声
            else:
                输出无有效回波

    发布带原始时序和正确坐标系的模拟扫描
    为评分器另存光路类别和真实命中标签
```

二次命中需要额外的场景射线查询模块或插件。只有一帧现成点云时，无法完整获得反射方向上未被原始扫描观测到的物体。可先实现明确声明的缺测故障注入，再实现几何反射，分别记录版本。

## 3. 第一轮实验设置

从 S1 静态房间派生 `S5_mirror`，保持机器人、路线、扫描配置、薄板位置和尺寸一致，仅改变薄板的传感器响应。先隔离镜面因素，再增加动态或长廊条件。

| 条件 | 传感器响应 | 测试内容 |
| --- | --- | --- |
| 普通板 | 普通表面测距 | 几何一致的基线 |
| 镜面缺测 | 命中镜面的部分方向无有效返回 | 有效约束减少 |
| 镜面虚像 | 按反射路径生成错误距离，可包含缺测 | 伪结构对建图和定位的影响 |

先做静止传感器检查，再移动采集。可在开发阶段测试距镜面 1、2、3 m、相对法向入射角 0°、30°、60°；这些是建议测试点，不是已测值。正式对比前固定场景、参数、轨迹和评分容限。

先检查原始扫描的异常是否与预期光路一致，再进行：

```text
建图会话 A 的镜面扫描
    → 基线方法 / 改进方法
    → 地图质量评价
    → 冻结地图
    → 同一份独立定位会话 B
    → 定位精度与持续输出评价
```

所有方法使用同源输入；B 的真值只评分。镜面几何和标签不能作为未声明的被测算法输入。

## 4. 需要记录的指标

| 层面 | 指标 | 说明 |
| --- | --- | --- |
| 传感器 | 镜面照射方向的缺测比例 | 无有效返回的镜面入射束 / 全部镜面入射束 |
| 传感器 | 虚假返回比例 | 模拟器标注为反射虚像的返回束 / 全部镜面入射束 |
| 地图 | 几何误差、完整率、伪占据比例 | 对照独立物理场景参考；评分区域和容限提前固定 |
| 定位 | 位置与旋转 RMSE、位置误差 P95 | 同一定位器、同一独立 B、配对初值及随机种子 |
| 定位 | 成功时间占比、有效输出覆盖 | 保留中断和失败，缺失输出不能补零误差 |

镜面本身可以完全静止。虚假反射返回应单列为观测异常，不能未经定义便归入真实动态点，以 DA 动态删除率替代镜面处理指标。动态清理和镜面异常处理可分别消融。

## 5. 深度相机与实物校准

当前通用 `depth_camera` 不等同于实物 D435 的完整成像和深度估计过程。LiDAR 的光程模型不能直接当作 D435 的设备响应模型；深度图缺测、虚假深度和跨帧变化需要单独验证。

建议先实现并验证 LiDAR 镜面模型，再用实物 Unitree L2 和 D435 在固定距离、角度、镜面尺寸和背景条件下分别采集数据，标定各自的异常比例和空间／时间分布。仿真参数标定与最终留出测试分开记录。
