# 从大方向收窄到动态建图

[English](MAPPING-FOCUS.md) · [主文](../HOME.zh-CN.md#假设) · [地图指标与时间点](MAP-METRICS.zh-CN.md)

“变化环境中的可靠建图与定位”适合作为大方向。“退化＋大变动＋定位自恢复”同时包含观测不足、地图失效、错误匹配和重定位，无法用一个清理算法或一个RMSE回答。本轮先控制位姿与定位器，只干预地图层。

**当前问题：给定多帧扫描与建图位姿，如何去除动态残影而保留静态结构；地图改善在什么条件下能降低独立定位误差？** “更干净”是可检验的中间结果，不是定位准确的充分条件。给定位姿实验隔离了清理能力，尚不能证明自主SLAM完整链路。

| 论文可见的小问题 | 本轮能回答什么 | 边界 |
| --- | --- | --- |
| [DUFOMap](https://arxiv.org/html/2403.01449v1)：利用三维可见性／空域证据分类动态点 | 多次观测是否提供足够自由空间证据；DA与SA如何变化 | 不负责估计建图位姿或凭空补足几何；本轮运行使用提供的位姿 |
| [BeautyMap](https://arxiv.org/html/2405.07283v1)：清理已有三维全局图，并恢复可能误删的静态结构 | 删除与保留的权衡；小场景参数是否损伤静态支持 | 离线方法；不是实时定位／在线SLAM，不能由清理率推出恢复能力 |
| [SRRG，IROS 2018](https://iris.uniroma1.it/handle/11573/1340118)：二维点云配准、合并及长期地图维护 | 原生二维是否也能去残影；跟踪失败是否先破坏输入条件 | 本轮短会话与已知起点，不等于完整长期多会话复现；图合并开关另行记录 |
| IR-MCL／AdaM-MCL | 已知地图下的观测模型、候选位姿与定位表现 | 定位参照，不是地图清理算法 |

原论文中，DUFOMap覆盖KITTI、Argoverse 2及半室内三维扫描；BeautyMap主要在KITTI和半室内三维图上验证；SRRG包含LCAS–STRANDS与MIT Stata多会话场景。我们的短量程、小室内、稀疏16线仿真与这些协议不同，迁移后指标下降不能单独说明论文不适用。[各方法适用数据与输入核对](MAP-2D-3D.zh-CN.md) · [SRRG论文与代码范围](../papers/srrg_mapper2d.zh-CN.md)。

## 从当前开放问题得到的三个检验

研究链条是**动态删除与静态保留的联合取舍→污染条件下的定位收益→收益成立的几何条件**。原M1／M2合并为M1；保留M4／M5编号，方便对应历史讨论。以下是待检验命题与计划，不表示新实验已经执行。

| 编号 | 待检验命题 | 对应开放问题 |
| --- | --- | --- |
| M1（合并原M1／M2） | 在重复观测和可信建图位姿下，存在能够实质减少动态残影、同时把静态损失限制在预设范围内的清理工作点。 | 能否同时做到删动态、留静态？ |
| M4（重写） | 控制静态支持与定位器时，测试匹配区域的动态残影污染越强，清理带来的配对定位误差／失败改善越明显；低污染时收益可能很小。 | 什么污染条件下，地图改善会转化为定位收益？ |
| M5（重写） | 相近DA／SA、点数和计算预算下，优先保留稳定、可重复观测、具有区分度及方向互补的静态结构，比均匀／仅阈值保留更有利于定位。 | 什么几何条件使“保留下来的静态结构”真正有用？ |

### M1：把动态删除与静态保留作为一个联合命题

固定源观测、时间戳、建图位姿和地图表示，对比Raw、作者清理方法及简单可见性／支持阈值对照。同时报告DA与SA、静态细结构覆盖和资源消耗；不把两项拆成两个成功结论，也不只凭综合平均分判断。最低动态去除要求、允许静态损失和容差应在独立开发数据上确定，并在新测试前固定；不能根据测试结果反调。

已有单轮三维观察为：DUFOMap的DA／SA是46.59%／99.998%，BeautyMap为74.36%／81.15%。它们展示取舍，不能宣称所有清理方法都能保住静态结构。二维SRRG的42.31%残影删除与99.51%静态覆盖采用另一口径，作为独立系统观察；其自估位姿不能混入给定位姿的受控排名。

**证伪条件：**在预先规定的场景、容差与预算内，找不到同时满足动态去除和静态保留要求的工作点，或所谓保留仅来自放宽容差，应否定该范围内的联合可行性。通过M1仍不能推出定位改善。

### M4：检验地图污染与独立定位收益之间的关系

先用建图会话A生成各张地图，再冻结地图，用同一份独立B、相同初值／配对随机种子及固定定位器比较。预先定义低／中／高污染及污染位置，位置来自A的几何或场景布置，不能看过B误差后专门挑选。除全图动态点比例，还记录污染是否位于可匹配区域、是否形成重复／误导结构。

优先使用固定观测与位姿的受控污染回放，并明确其构造方式；若另行采集不同动态条件，静态可见性也可能变化，需要分别报告，不能当作只改变污染的单因素实验。每个条件内，各方法必须使用同源输入。原始图、清理图和简单阈值对照在相近静态保留与资源预算下比较，无法匹配时报告取舍曲线。

预先规定改善量为`Raw误差−清理图误差`，正值表示改善，同时报告姿态误差、尾部误差、失配／跟踪失败和有效输出覆盖。使用共同时间窗评分，并保留各组全时覆盖，避免失败组因缺少输出而得到较低RMSE。独立场景／采集会话与同输入重复种子分开统计。

已有动态GICP的Raw／DUFO／Beauty XYZ RMSE为0.98／0.98／1.04cm，尚未建立收益。约1%的全局动态点占比只是候选解释，不能证明收益随污染变化。受控关系、重复验证与SRRG独立定位B都待测。

**证伪条件：**在声明的污染范围内，控制静态支持后仍看不到预测的配对收益变化，或收益由定位器调参、输出缺失或额外静态数据解释，应否定对应关系。“清理未改善本场景定位”与“清理没有删除动态点”是不同结论。

### M5：检验静态约束分布，而非预设增加传感器

固定地图来源、维度、定位器和B观测，对比均匀保留／仅阈值策略与几何结构保护策略。后者只用A的几何和多帧稳定性选择候选结构，例如分散的角点、端墙、不同朝向表面；不得用B真值或B误差决定留哪些点。先在开发集匹配DA／SA、点数、分辨率与计算预算，再在留出条件上比较；无法严格匹配时报告前沿，不能把“多留点”当作几何策略的收益。

分别检查几何丰富房间、平行走廊及能看见转角／端墙的对照。记录保留结构的空间／方向覆盖、对应分布与弱约束方向，再比较独立定位。转角／端墙对照属于另一场景条件，不能把加入结构后的成绩称为原走廊恢复。原场景没有可见互补结构时，清理和点选择都不能凭空补出信息。

**现有状态：**尚无匹配DA／SA与预算的几何保留消融。走廊失败只提供边界线索；历史Depth实验改变了定位观测，不能验证地图选择机制。深度相机是后续可选扩展，不再定义M5。

**证伪条件：**与简单保留基线相比，在独立场景中没有可重复收益，或收益可由点数、全局SA／DA、额外输入或计算预算解释，则不支持几何结构保护的额外价值。

## 原M3改为表示与评分诊断

二维投影属于表示／评测接口选择，不能因三维点删除率与二维格删除率不同，就假设或判定“清理收益被吞掉”。原8.33%／33.33%的二维动态格删除结果继续保留，但不再标为对M3的部分支持或反驳。

若研究投影的影响，应固定同一批源观测和位姿，在同一占据定义下逐格追溯剩余支持，分别检查高度带、多点落入一格、膨胀及未知／自由空间处理；之后仍需独立定位检验。原生二维SRRG与三维方法投影分别评价，不靠不同分母给出跨表示结论。

## 负结果与边界对照

静态场景没有动态删除需求，DA为N/A。平行走廊缺少几何约束，清理不能增加不存在的结构；先排查跟踪和有效输出覆盖。持久变化需区分新增、移除以及遮挡，旧图定位没有调用更新时不能评价地图更新算法。SRRG图合并开启时出现数值崩溃属于实现／数值诊断，不等同于论文理论失效。

已有Guard／Depth／Search只改变定位，在冻结地图上测试，保留在[历史定位探索](HYPOTHESES.zh-CN.md)，不作为M4污染关系或M5几何保留机制的验证。SRRG记录中的建图跟踪误差也不能替代另一次AMCL定位B误差。
