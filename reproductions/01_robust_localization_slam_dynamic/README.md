## 本方向要回答的问题

> 环境里有东西在动、有东西被搬走、还有白墙暗光这类让传感器退化的条件时，
> 地图还能不能用来定位？清理掉的东西，到底是**让定位变好还是变坏**？

本方向的复现链就是为了把这个问题变成数字：先用统一指标测「清理得干不干净」（F1），
再用下游定位器测「清理完还能不能定位」（配准失败率 / ATE），最后看两个排名是否一致。

> **H1′（来自任务书 §6 并行实验）**：两种排名不一致（Spearman ρ < 0.9），
> 且假阳性来自**可观测性低**的区域。若 ρ > 0.9，假设被证伪——这也是可报告的结论。

### H1′ 实测结果（2026-10-05，141 帧 KITTI 00，6 张地图）

跑法：每张清理后的地图先**统一体素到 0.2 m**（否则测的是"谁的点更密"而不是"谁清理得好"），
再用 Open3D 点面 ICP 把每一帧的扫描配准进去，初始位姿给出一个**故意错开的初值**；
成功 = 终点误差 < 0.2 m 且 < 2°，且内点率 ≥ 0.30。完整协议与限制见
[`02_kiss_icp/work/registration_utility.py`](02_kiss_icp/work/registration_utility.py)。

| 地图 | 提交口径 SA / DA / AA | 归一化后 SA / AA | 配准失败率（0.5 m, 5°） | （1.0 m, 8°） | **（2.0 m, 12°）** | （3.0 m, 20°） |
| :--- | :--- | :--- | ---: | ---: | ---: | ---: |
| uncleaned（不清理） | 100 / 0 / 0 | 19.38 / 37.91 | 0.0 % | 0.7 % | 17.0 % | 51.1 % |
| **erasor（基准重实现）** | 66.71 / 98.54 / 81.07 | 13.91 / 37.21 | **19.9 %** | **19.9 %** | **29.1 %** | **57.4 %** |
| removert（官方仓库） | 99.62 / 89.25 / 94.29 | 16.93 / 40.51 | 0.0 % | 0.7 % | 12.1 % | 43.3 % |
| removert（基准重实现） | 99.44 / 41.53 / 64.26 | 19.44 / 41.18 | 0.0 % | 0.7 % | 11.3 % | 44.0 % |
| dufomap | 97.96 / 98.72 / 98.34 | 19.22 / 43.78 | 0.0 % | 0.7 % | 11.3 % | 44.0 % |
| beautymap | 96.95 / 98.34 / 97.64 | 18.92 / 43.40 | 0.0 % | 0.7 % | 14.9 % | 46.8 % |

**结论：H1′ 成立，而且比预期更尖锐。**

| 对比 | Spearman ρ | 判读 |
| :--- | ---: | :--- |
| 归一化 AA 排名 vs 定位效用排名 | **0.78**（各档 0.55–0.78） | < 0.9 → 两种排名**不一致**，H1′ 成立 |
| **提交口径 AA** 排名 vs 定位效用排名 | **0.38** | 更要命：**论文表格里印的那套指标，最不能预测地图好不好用** |
| 提交口径 SA 排名 vs 定位效用排名 | 0.23 | 同上 |

三条具体结论：

1. **ERASOR 是唯一在"轻微初值误差"下就失败的图**：初值只错 0.5 m / 5° 时它已经
   **19.9 %** 配准失败，其余五张全是 **0 %**。而它在基准表里 DA 最高（98.54）。
   → 「删得干净」与「删完还能用」是两件事。
2. **不清理（uncleaned）在大初值误差下反而更差**（51.1 % vs 清理过的 43–47 %）：
   说明清理**确实**提升了定位可用性 —— 但提升来自"去掉动态杂波"，而不是来自表格指标的高低。
3. **提交口径的 SA/AA 排名与定位效用几乎不相关**（ρ 0.23 / 0.38），而**归一化到同一分辨率之后**
   相关性才升到 0.78 —— 也就是 01-03 早就发现的那件事（0.05 m 最近邻规则把**下采样**读成了**删除**）
   在这里第二次出现，而且这次是**下游**证据。

> ⚠️ **两条必须一起读的限制**（写在 `reproduction_utility.py` 的 docstring 里）：
> ① 这是**自配准**（地图就是这 141 帧建的），绝对失败率偏乐观，能成立的只有**排名对比**；
> ② 官方 ERASOR 的地图在**另一个坐标系**（官方 bag 的 SuMa 帧，与基准世界系中位差 ~1.6 m），
> 因此被**排除**而不是当成一张"差地图"打分 —— 这也是 01-03 的一条实测结论。

**为什么这组实验值得先做**：不需要任何自采数据、不需要 GPU、全部资产公开，
而且它验证的正是主任务 §4.1「删除判据」—— 现在它有了数字。
