# 从接收数据到定位：测试顺序与预期

本文件中的数值门槛是本项目建议的初期工程验收目标，**不是厂家承诺、论文成绩或已经达到的结果**。正式实验前按验证集冻结门槛；保留所有失败。硬件连通、受控测距、定位、地图研究分别验收。

## 1. 先验收采集和时间

启动阶段单独保留记录；稳态帧率和间隔从首次帧交付后至少 2 秒再统计，不能静默删除启动帧。同步帧组可能重复慢帧或省略启动帧；原始文件验收使用 SDK 单路回调与 SQLite 消息计数，并检查所有实时帧号都保留。启动延迟与稳态长停顿分别报告。

| 检查 | 操作与应看到的画面 | 建议初期门槛／正常解释 |
| --- | --- | --- |
| D435 四路 | 固定 60 秒，墙角、纸箱、家具距离约 1–3 m；RGB、左右灰度 IR、伪彩深度同步展示 | 640×480、30 fps 配置下，每路 29–31 fps；帧号缺失 <1%；时间不倒退，无 >100 ms 长停顿 |
| 深度 | 相机静止，对准哑光平面；近远平面颜色区分，边缘基本稳定 | 选定目标 ROI 有效深度 >90%；2 m 哑光平面中央中位深度的时间标准差先要求 <10 mm。玻璃、黑亮物、轮廓、遮挡边缘的空洞可以正常出现；整面普通墙持续无深度需排查 |
| 测距 | 卷尺独立量 1、2、3 m 的标记平面；对相同表面做 ROI 中位值，先记录光心基准与尺量误差 | 先要求绝对偏差 <max(3 cm, 距离×2%)，计入尺量不确定性。当前 2.083 m 数字没有尺量参考，不能据此判准确 |
| L2 点云 | 底座固定水平，展示俯视、侧视和 3D；选取墙、地面与箱子 | 稳定墙面应为平面，点密度随积累时间增大；细杆、远处、低反射物可以稀疏。全房间伸缩、持续双墙、固定时整图旋转异常 |
| UART 质量 | 连续录制 60 秒再离线 CRC／序号／帧尾检查 | CRC 理想为 0；初期拒绝比例 <0.1%、包缺失 <0.1%。超标先检查线缆、USB 集线器、驱动、缓冲；CRC 错误包不进入地图 |
| L2 频率 | 同时报原始设备时间频率和主机接收频率 | 当前约 216 线包/s、250 IMU 包/s。不能把 216 线包/s、默认 18 线聚合约 12 cloud/s、实测下电机约 4.36 转/s混为一个“帧率” |
| IMU 静止 | 固定至少 60 秒，记录加速度、角速度、四元数、温度 | 加速度模长应接近当地重力，四元数范数接近 1；静止角速度均值先以 <0.05 rad/s 为排查目标。单位、轴、偏置、转动电机振动均须核实；IMU 不提供位置真值 |
| 时间 | 拟合 `host_receive_elapsed = a × device_elapsed + b`，检查原始时间间隔与逐点 time | 进入惯性定位前要求解释清楚比例／偏移，时间不倒退；建议独立时钟的比例差 <1000 ppm，受控同步残差 p95 <5 ms。USB 接收抖动不能代替采样时刻误差；硬件同步精度另验 |

最新固定 60 秒会话中，L2 的 `a≈1.99866`，官方 SDK 原生解析保留原值，原始时钟时间门槛失败。SDK 主机解析时间选项已通过有节奏回放核查，但不等于设备时间修复或硬件同步。固定 IMU 均值接近零、波动较大；主机时间重采样频谱约 4.36 Hz 与电机频率接近，仍需单位／轴／标定和受控对照。不得用“全部乘 2”覆盖原始时间。详细实测见 [基线报告](BASELINE_RESULTS.zh-CN.md)。

本机 D435 **没有 IMU**，相机的视觉惯性模式暂不适用。L2 的 IMU 也不能在没有刚性外参、时间标定的情况下替代相机 IMU。

## 2. 通用定位算法：每个算法应呈现什么

RTAB-Map Stereo、RTAB-Map ICP 与 KISS-ICP 已在本次静止录制上运行，结果见 [第二轮报告](DIAGNOSTICS_ROUND2.zh-CN.md)。下表其他路线尚待执行；静止通过不能替代移动／回环验收。

| 算法／输入 | 视频应展示的内容 | 正常现象与失败特征 | 重点指标 |
| --- | --- | --- | --- |
| RTAB-Map Stereo；D435 左右 IR | 左右图像、内点数、轨迹、稀疏局部地图；添加 SLAM 节点后才评价位姿图与回环 | 静止轨迹应贴近原点；稀疏地图正常，不要求稠密彩色房间。本次静止通过，过曝和投射纹理的移动可靠性未验 | 状态和位姿覆盖、lost、静止偏离与转角、计算与回调延迟；有参考后才量移动精度 |
| ORB-SLAM3 Stereo；D435 左右 IR | 左右图像特征点、跟踪状态、相机轨迹、关键帧与稀疏地图 | 起步建立地图后，慢平移应出现对应轨迹；重访可能触发回环并调整历史轨迹。稀疏点地图是正常结果，不要求彩色稠密房间；空白天花板、直射灯与运动模糊可造成跟踪丢失 | 跟踪成功率、丢失次数／持续时间、帧耗时、终点偏差；有独立参考时 ATE／RPE |
| RTAB-Map RGB-D；D435 RGB+对齐深度 | RGB、深度、里程计、位姿图、彩色点云地图；标记回环发生时刻 | 静止墙稳定、慢走时房间逐步形成；回环可修正累积偏差。纹理不足或深度无效可失败；持续重复平行墙通常提示位姿／标定／时间问题 | 里程计有效率、回环候选与确认数量、地图墙厚、处理延迟、峰值内存、ATE／RPE |
| KISS-ICP；L2 3D 点云 | 当前扫描、局部地图、轨迹；固定相机视角对比墙面 | 已运行：官方点云静止仍偏离 41.54 cm／179.71°，异常。默认里程计没有全局回环保证，不能期待自动全局闭合 | API 未提供 lost，有限位姿不代表正确；记录对照残差、每帧耗时、静止漂移、路径终点偏差；逐点时间可用后对照去畸变 |
| RTAB-Map ICP；L2 3D 点云 | 原始扫描、估计轨迹、依位姿累积的地图；同步显示状态与漂移 | 本次已运行：50 线聚合吞吐通过，但固定时仍偏离约 19 cm／16°，不正常；TRACKING 不等于正确 | 输出覆盖、ICP 对应比例／结构诊断、静止偏离、耗时；分别报告聚合周期与是否去畸变 |
| Unitree Point-LIO；L2 点云+IMU | 去畸变扫描、重力对齐地图、位姿和 IMU 曲线 | 初始化前数秒必须固定；转动时墙面应保持平直。默认不能假设全局回环；“有平滑轨迹”不证明正确。重影、Z 轴持续振荡、地图扭曲需检查时间、IMU 单位与外参 | 初始化成功率、静止漂移、IMU 残差、墙厚、延迟、ATE／RPE；**当前先过时间门槛** |

官方入口：[ORB-SLAM3](https://github.com/UZ-SLAMLab/ORB_SLAM3)、[RTAB-Map ROS](https://github.com/introlab/rtabmap_ros)、[KISS-ICP](https://github.com/PRBonn/kiss-icp)、[Unitree Point-LIO](https://github.com/unitreerobotics/point_lio_unilidar)。Unitree Point-LIO 官方验证环境是 ROS1 Noetic；本机主要为 WSL Ubuntu 22.04／ROS2 Humble，须选择并固定明确的适配方案，不把 ROS1 launch 当作 ROS2 命令。

建议优先 D435 Stereo／RGB-D 和 L2 KISS-ICP 两条独立基线；L2 的惯性定位在时间与静止 IMU 验收后开展。双设备融合放在刚性安装、相机—雷达外参、时钟偏移与漂移验证之后。

## 3. 运动流程和指标怎么量

1. 固定 60 秒，录制原始数据与屏幕；这段用于通信、静止噪声和算法静止漂移。
2. 沿尺量的直线慢移约 2 m，起止各固定 5 秒，重复 3 次；不要拽着两个没有刚性固定的传感器一起晃动。
3. 静止位置慢转约 90°再回来；检查坐标轴方向、轨迹响应与墙面去畸变。
4. 慢走 5–10 m 小闭环，回到胶带标记的同一位置和朝向，起止固定；分别保存回环前后的轨迹。闭环视频不能只剪最终漂亮一帧。
5. 单独做故障对照：快速运动、白墙、遮挡、纹理不足；记录恢复过程，不与正常工况混成一个均值。

初期建议：静止 60 秒位姿平移范围 <5 cm、旋转范围 <2°；2 m 尺量直线终点距离偏差 <5% 并考虑参考误差；5–10 m 小闭环终点偏差先要求 <20 cm；正常慢走跟踪可用比例 >95%；实时处理的 p95 单帧耗时应小于输入周期，且排队延迟不随时间增长。对没有回环的里程计单独注明终点漂移，不能宣称“闭环优化通过”。这些目标在结构退化场景不保证成立。

**ATE／RPE 需要独立参考轨迹。** 可用经独立测量的多标记板／外部定位系统，并报告参考精度。另一套 SLAM 轨迹、L2 IMU、算法自己的回环都不能当真值。只有尺量起终点时，报告距离误差和终点偏差，ATE／RPE 填“不具备参考”，不得计算伪 ATE。具有真值后，可先以 ATE RMSE <10 cm、每 1 m 相对位姿平移误差 <5 cm作为小房间初期目标；同时报告转角误差、匹配覆盖、对齐方式与失败会话。

视频统一同时显示：真实输入、当前状态、地图／轨迹、时间轴、关键指标。明确标注 LIVE、OFFLINE ALGORITHM 或 SAVED OUTPUT REPLAY；2D 点云投影属于原始传感器预览，不能叫定位视频。
